# 完整链路梳理：发射端 → 无线信道 → 接收端（单载波QAM，收发RRC配对 + 4×ADC过采样 + Gardner定时恢复 + T/2 FSE均衡，就是咱们前面一直在聊的这套架构）

约定符号： 符号周期 $T$，波特率 $R_s=(1/T)$；滚降系数 $\alpha$，成型带宽 $B=(1+\alpha)/T$ 信号形式标记：**模拟连续 / 数字离散（复数 $(I+jQ)$）**

> 核心思路：发射端先把比特变成适合信道传输的带限脉冲波形；信道引入失真；接收端一步步把失真、不同步的波形还原回原始比特。

---

## 一、发射端流程

### 1. 比特流（二进制0/1）→ 星座映射（符号映射）

- 工作内容：把一组比特映射成一个复数星座点（QAM：如16QAM每4bit映射1个复数值 $a_k=I_k+jQ_k$）
- 信号形式：**符号序列，离散复数，速率 $(1/T)$（波特速率，1个符号/T）**
- 处理方式：查表映射
- 解决问题：把二进制比特变成适合调制的复基带符号
- 问题来源：射频载波只能传输波形，不能直接传0、1

### 2. 上采样（插零）

- 工作内容：在每一个符号 $a_k$ 后面插入 $L-1$ 个0；例：成型滤波器按4倍过采样设计，$(L=4)$，每符号插3个0
- 信号形式：离散复数，速率 $(4/T)$
- 处理方式：插零
- 解决问题：提升采样率，和后面数字成型滤波器的采样率匹配
- 问题来源：RRC成型FIR是工作在高采样率上，不能直接对波特率符号滤波

### 3. 发射RRC脉冲成型滤波（数字FIR）

- 工作内容：插零后的序列和RRC脉冲响应做卷积；把离散符号变成平滑、带限的奈奎斯特脉冲波形，抑制带外泄漏
- 信号形式：离散复数基带波形，速率 $(4/T)$
- 处理方式：复数FIR卷积（I、Q两路共用一套实RRC抽头）
- 解决问题：
    1. 限制信号带宽，防止干扰邻道；
    2. 设计脉冲：收发配对后总响应为升余弦RC，理想信道、定时对准下，采样点ISI=0
- 问题来源：直接发送冲激式符号频谱无限宽，会严重带外辐射、干扰别人

### 4. 数字上变频 DUC

- 工作内容：把数字基带复数信号，搬移到中频（IF）
- 信号形式：离散中频复数信号
- 处理方式：乘以复载波 $e^{j2\pi f_{if}nT_s}$
- 解决问题：基带信号频率太低，无法直接射频发射
- 问题来源：天线需要射频频段信号辐射

### 5. DAC 数模转换 + 模拟射频上变频 + 功率放大 + 天线发射

- 工作内容：DAC把数字中频转为模拟波形；射频本振把中频搬移到射频载波频率，放大，天线辐射
- 信号形式：**模拟射频连续带通信号（实信号）**
- 处理方式：D/A、模拟混频、功放、天线辐射
- 解决问题：把数字波形转为电磁波，送入无线信道
- 问题来源：数字信号不能直接辐射

---

## 二、无线信道（天线之间）

- 工作内容：电磁波传播
- 信号形式：模拟射频连续带通信号
- 信道引入损伤（全部是接收端后面模块要逐一修复的根源）
    1. **传播时延**：固定时间偏移（定时静态相位）
    2. **多径**：多条反射路径，相当于线性滤波器，造成频率选择性衰落、波形畸变 → 多径ISI
    3. **多普勒频移（移动场景）**：等效时钟频偏、载波频偏
    4. **加性高斯白噪声AWGN**
    5. 信道幅度/相位畸变
- 处理方式：自然物理过程，无人工处理
- 解决问题：无，这是损伤源，接收端补偿

> 重点：信道**不会区分载波相位、定时相位、多径畸变**，全部叠加在一起送到接收天线。

---

## 三、接收端（就是咱们讨论的链路，顺序严格对应）

> 接收天线 → 射频前端 → 下变频 → 模拟抗混叠滤波 → ADC → 数字RRC匹配滤波 → 定时同步（TED+环路滤波+插值）→ 插值重采样+抽取 → FSE分数间隔均衡 → 载波同步（很多方案放这里，也有均衡联合载波恢复）→ 判决 → 解映射 → 比特输出

### 接收1：天线接收 + 低噪放 + 射频下变频

- 工作内容：天线拾取射频电磁波；低噪放放大；射频本振混频，把射频信号搬回模拟基带
- 信号形式：**模拟连续复基带信号 $(i(t)+jq(t))$**
- 处理方式：模拟混频、放大
- 解决问题：把高频射频信号搬回基带，方便数字化
- 问题来源：射频载波频率太高，ADC无法直接采样射频

### 接收2：模拟抗混叠滤波

- 工作内容：模拟低通，滤除高于ADC奈奎斯特频率的高频分量
- 信号形式：模拟连续复基带
- 处理方式：模拟滤波器
- 解决问题：防止ADC采样发生混叠
- 问题来源：ADC采样是离散采样，高于奈奎斯特频率分量会频谱折叠混叠

### 接收3：ADC采样（固定硬件采样时钟，例子4×过采样，$f_s=(4/T)$）

- 工作内容：模拟基带 → 离散数字复数样点 $(x[n]=I[n]+jQ[n])$
- 信号形式：**离散复数基带，固定采样网格，4样点/符号**
- 处理方式：A/D模数转换；采样时刻由硬件晶振固定，不可直接改动
- 解决问题：模拟信号转为数字，交给DSP/FPGA处理
- 问题来源：数字算法只能处理离散数字样点
    
    > ⚠️ 重要：此时已经是数字I/Q；但是：带噪声、带信道畸变、定时相位未知、载波相位未知
    

### 接收4：数字RRC匹配滤波（FIR卷积）

- 工作内容：I、Q两路分别和RRC抽头卷积；和发射RRC配对
- 信号形式：离散复数基带，仍然4样点/符号，采样网格不变
- 处理方式：复数FIR滤波
- 解决问题：
    1. AWGN下匹配滤波，在脉冲峰值处最大化SNR；
    2. 脉冲能量汇聚，形成清晰RC脉冲峰，给后面TED定时误差检测提供高质量波形；
    3. 理想无畸变信道下，配对RRC合成为RC奈奎斯特脉冲
- 问题来源：接收信号波形弥散、噪声高；TED需要清晰脉冲轮廓才能估计定时误差
    
    > 注意：**RRC不能修正定时相位、不能补偿多径畸变**
    

### 接收5：定时同步环路（Gardner TED + 环路滤波 + 插值）

- 工作内容：
    1. TED（定时误差检测器）：拿RRC输出的离散样点，估算当前采样网格相对于脉冲峰值的时间偏移 $\tau$（定时误差）；
    2. 环路滤波：平滑误差、抑制噪声，输出需要校正的偏移量；
    3. 插值：用周围已有的离散I/Q样点，估算目标时间位置（脉冲峰值附近）的I/Q值（虚拟重建带限波形、在目标时刻求值，全程数字域）
- 信号形式：仍然是离散复数基带，插值输出新的离散样点序列
- 处理方式：误差估计算法、环路滤波、数字插值多项式
- 解决问题：**校正定时相位（时间偏移），让采样时刻对准脉冲主峰** 消除定时偏移带来的定时ISI、提升采样SNR； 输出后做抽取，降到2样点/符号（T/2，给FSE）
- 问题来源：收发晶振存在ppm级频差、传播时延、多普勒，导致采样网格和脉冲峰值错位
    
    > 区分：定时相位 = 时间轴偏移；**不是载波星座旋转**
    

### 接收6：插值重采样+抽取，得到2样点/符号（T/2），送入FSE分数间隔均衡

- 信号形式：离散复数基带，$f_s=2/T$（每符号2个I/Q样点）
- 处理方式：抽取（丢掉多余样点）
- 为什么不降成1点/符号（波特SRE）： 当 $\alpha>0$，信号带宽 $B>(1/T)$，波特采样会频谱混叠，均衡性能严重依赖定时相位； T/2 FSE规避波特采样混叠，对定时相位鲁棒性更强
- 解决问题：给FSE提供不混叠、双相位分支的输入
- 问题来源：波特间隔均衡SRE天生的频谱混叠、零点敏感问题

### 接收7：FSE分数间隔均衡（自适应均衡）

- 工作内容：自适应FIR滤波器，不断更新抽头系数，补偿信道带来的频率选择性畸变（多径）
- 信号形式：离散复数基带
- 处理方式：自适应算法（LMS/RLS等）
- 解决问题：**补偿多径信道造成的波形畸变、多径ISI**
- 问题来源：信道多径把原本满足奈奎斯特的脉冲扭曲了，就算定时采得再准，采样点依然存在ISI

> 很多工程实现：**载波同步（载波频偏、载波相位旋转）放在均衡前/均衡内部联合估计** 载波同步：复数乘以 $e^{-j\theta}$，星座整体旋转摆正；解决本振不匹配带来的载波相位/频偏

### 接收8：判决（ slicer，星座判决）

- 工作内容：把均衡输出的复数I/Q，判定为离它最近的标准QAM星座点
- 信号形式：判决后的离散符号 $\hat a_k$（复数星座点，波特速率，1点/符号）
- 处理方式：欧式距离判决
- 解决问题：从带噪声、残留误差的I/Q，还原发射的符号
- 问题来源：均衡输出仍然有噪声、残余误差

### 接收9：星座解映射

- 工作内容：把判决出来的复数星座点，映射回比特组
- 信号形式：二进制比特流
- 处理方式：查表解映射
- 解决问题：复数符号变回原始比特
- 问题来源：发射端做了星座映射，接收端反向还原

# 一张总表，把三类ISI根源单独拎出来（贯穿你前面所有提问）

|失真类型|产生位置|负责修复模块|
|---|---|---|
|成型ISI（原本奈奎斯特要消除的）|发射脉冲成型|收发配对RRC|
|定时偏移ISI|收发时钟/传播时延|定时同步+插值|
|多径ISI|无线信道反射多径|FSE自适应均衡|
|载波相位旋转|本振、多普勒|载波同步PLL/Costas|

# 一句话极简总逻辑串讲

发射端：比特→QAM符号→插零+RRC成型（做成带限无ISI脉冲）→上变频→电磁波； 信道：加上噪声、时延、多径、多普勒； 接收端：射频下变频→模拟抗混叠→ADC数字化（4×过采样数字I/Q）→RRC匹配滤波聚脉冲、提SNR→定时同步插值对准采样时刻→降采样到T/2→FSE均衡抹平多径畸变→载波同步摆正星座→判决解映射→恢复比特。
